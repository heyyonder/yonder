# Getting started

## 1. Install Yonder on your computer

Install Yonder on the computer that runs your agents. Follow the doc of
your platform: [macOS](../setup/macos.md), [Windows](../setup/windows.md)
or [Linux](../setup/linux.md).

The first run asks which CLI you use, such as Claude Code. Its last step
starts that agent, and the agent sets up the rest with you.

## 2. Pair your phone

1. Install the phone app: [iPhone](../setup/iphone.md) or
   [Android](../setup/android.md).
2. On the computer, open **Settings › Pair a phone**. On a Linux server,
   run `yonder pair`.
3. Scan the QR code with the phone app.

The code works one time, for 5 minutes. The phone and the computer now
trust only each other.

## 3. Start your first agent

1. Tap the **+** button, or say the task in the notch of the Mac (tap the
   right ⌘ key).
2. Type what you want, such as "Fix the typo in the README title".
3. Send it.

Yonder picks the workspace from your words, starts the agent, and shows it
in the list at once. When the agent is done, its result shows in the chat,
and the phone tells you.

Next: read [Agents](agents.md).
