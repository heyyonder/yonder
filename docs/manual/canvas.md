# Canvas and Preview

## Canvas

The Canvas tab shows what your agents make and ask:

- the pages and small apps that an agent makes for you,
- the web sites that run on each computer,
- the approvals that wait for you.

Star an app to keep it at the top. Ask an agent to change an app, or to
build a new one: "make me an app that shows my open pull requests".

## Preview

Preview opens the dev server of an agent, such as `http://localhost:5173`,
on your phone, through a private HTTPS tunnel. Tap the link in the chat of
the agent. The first time for a workspace, Yonder asks for your yes before
it opens the tunnel.

An agent cannot open a site by itself. It names the address in its final
message, and you open it.
