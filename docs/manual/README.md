# Yonder user manual

This manual tells how to use each part of Yonder. To install it, read
[Setup](../setup/README.md). To learn how it works inside, read
[How Yonder works](../guide.md).

| Chapter | What it tells |
|---|---|
| [Getting started](getting-started.md) | Install, pair your phone, and start your first agent. |
| [Agents](agents.md) | Start, follow, answer, stop, close and continue an agent. |
| [Names and numbers](names.md) | Call your agents by number, by name, or by your own word. |
| [Workspaces](workspaces.md) | Group your agents, with a home folder or none. |
| [Profiles](profiles.md) | Choose the CLI and the account of each agent. |
| [Computers](computers.md) | Use more than one computer from one phone. |
| [People on one computer](people.md) | Share one computer, each person with their own phone and agents. |
| [Canvas and Preview](canvas.md) | See the pages, apps and sites that your agents make. |
| [Schedules and triggers](automation.md) | Start agents at set times, or when something happens. |
| [Look and themes](themes.md) | Change the look, or let an agent build your own screen. |
| [Claude and MCP](mcp.md) | Use Yonder from the Claude app or any MCP client. |
| [Voice](../voice/README.md) | The optional voice module. |
| [Back up and move](backup.md) | Safe saves, and Export and Import of your setup. |
| [Settings files](settings.md) | The files that you or an agent can edit by hand. |
| [Troubleshooting](troubleshooting.md) | What to do when something does not work. |

Each change that you make in the app is also a tool that an agent can
call. So you can ask an agent to do any step of this manual for you, such
as "rename agent 4 to Landing page" or "star the shop workspace".
