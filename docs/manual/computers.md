# Computers

Each computer that runs Yonder is an **environment**. One phone can pair
with many computers: a Mac, a Linux server and a Windows PC.

## Add a computer

1. Install Yonder on the other computer.
2. On the phone, open **Settings › Environments › Pair a computer**.
3. Scan the QR code of the new computer.

## Use more than one computer

- The phone stays connected to each computer, and shows their workspaces
  and agents in one list, under the name of each computer.
- The **environment button** in the title bar picks All environments or
  one computer. A pick of one computer acts as if you work on it: a new
  agent starts there. On the Mac, ⌘E moves to the next computer.
- Rename a computer in its details (i) on the phone, or in **Settings ›
  Environments › Name** on the Mac.
- Hide a computer with its switch. It stays paired.

In a call or a chat with Claude, name the computer: "On the Linux server,
start an agent that updates the packages."
